Producto a desarrollar:

Debemos realizar una aplcacion funcional para una escuela de idiomas. 
Esta servirá para registrar alumnos solicitando su nombre, apellido, edad, números de telefono, correos, idioma a aprender y si han estado en el centro o no para diferenciarlos entre primer curso o segundo.
Por otro lado los profesores se pediran los mismos datos menos la pregunta de si han estado en el centro, y se les asignarán clases segun el idioma que impartan.

La segunda aplicación recibirá todos estos datos, y organizará las clases según sus capacidades, mediante apellidos, curso e idioma devolviendo la información al primer programa, para que así este pueda ver que profesores imparten "x" idioma "x" curso y qué alumnos.
